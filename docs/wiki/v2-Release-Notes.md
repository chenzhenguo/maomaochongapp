# v2版本更新说明

## 主要变化

### 1. 架构重构
- **从单页面升级为Tab架构**：设置、文件、复制、下载四个独立Tab
- **简化目录结构**：移除了"绘本集/绘本名称"的复杂层级，直接使用点读笔标准目录结构
- **专注核心功能**：专注于毛毛虫点读笔的实际使用场景

### 2. 新增功能
- **下载导入**：支持从URL列表下载音频并自动按序号命名
- **序号管理**：按子目录分别维护序号，支持自动递增和避免重复
- **目标子目录预设**：提供标准点读笔目录（MP3、DIYAUDIO、REC等）的快速选择

### 3. 用户体验改进
- **预览优先**：所有批量操作先预览再执行
- **冲突检测**：自动检测并提示各种冲突情况
- **持久化设置**：保存源/目标目录、序号配置等设置
- **调试支持**：完善的调试日志和导出功能

### 4. 技术改进
- **SAF权限优化**：更好的持久化授权处理
- **异步处理**：所有IO操作在后台线程执行，避免UI卡顿
- **错误处理**：完善的错误处理和用户反馈
- **单元测试**：核心逻辑有完整的单元测试覆盖

## 使用流程对比

### v1版本流程
1. 选择源文件夹
2. 设置重命名规则（三种模式）
3. 设置导出路径（绘本集/绘本名称/目标子目录）
4. 执行改名或导出

### v2版本流程
1. **设置页**：一次性配置源/目标目录和序号
2. **文件页**：查看和选择文件
3. **复制页**：批量复制到目标子目录（自动序号命名）
4. **下载页**：从URL下载并自动序号命名

## 目录结构对比

### v1版本
```
目标目录/绘本集/绘本名称/目标子目录/文件名
```

### v2版本
```
目标目录/目标子目录/文件名
```

## 序号管理

v2版本引入了强大的序号管理功能：
- **按子目录维护**：MP3、DIYAUDIO、REC等目录分别维护自己的序号
- **自动扫描**：可以一键扫描目标目录现有文件，自动跳转到下一个可用序号
- **避免重复**：默认开启，确保新文件不会与现有文件序号冲突
- **手动调整**：支持手动修改当前序号

## 兼容性说明

v2版本保持了向后兼容性：
- 仍然支持原有的重命名规则（点读贴REC、顺序编号、正则替换）
- 文件页仍然支持在源目录内直接改名
- 所有SAF权限和文件访问逻辑保持不变
