# 毛毛虫资源管家

安卓离线工具：批量重命名资源，并按点读笔常见目录结构复制导出（基于 SAF）。

## 功能

- **文件管理**：查看源/目标目录文件，支持批量选择
- **批量改名**：支持序号前缀、正则替换等多种命名模式
- **复制导出**：选中文件按序号重命名后复制到目标子目录
- **下载导入**：输入 URL 列表，自动下载并按序号命名
- **序号管理**：按子目录维护序号，支持自动递增、避免重复

## 使用流程

1. **设置页**：选择源文件夹和目标存储文件夹（点读笔磁盘根目录）
2. **文件页**：选择要处理的文件
3. **复制页**或**下载页**：生成预览并执行

## 技术栈

- Kotlin + Jetpack Compose
- SAF (Storage Access Framework) 文件访问
- MVVM 架构

## 开发团队工作流

本项目采用5人开发团队模式，每个代理负责特定领域：

1. **开发代理** - 功能实现和UI开发
2. **调试代理** - Bug识别和修复
3. **测试代理** - 全面测试覆盖（80%+目标）
4. **安全代理** - 安全审查和漏洞预防
5. **发布代理** - 发布准备和自动化

详细配置请参阅 `.agents/team-config.md` 和 `.agents/handoffs/` 目录中的交接模板。

### CI/CD
- **CI流程**: 推送到main分支或创建PR时自动运行测试
- **发布流程**: 通过git tag触发自动发布（格式: `v*`）

### 贡献指南
1. 遵循现有的MVVM架构模式
2. 所有新功能必须包含单元测试
3. 使用SAF进行文件操作，不要直接访问文件系统
4. 在提交前运行本地测试：`./gradlew test`
