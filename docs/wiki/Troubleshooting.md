# 常见问题排查

## 1) "当前目录没有可处理的文件"

触发点：`MainViewModel.buildPreview()`。

可能原因：
- 选择的目录下没有文件（只有子目录）
- 资源在更深层级，需在系统选择器中进入子目录再选

## 2) 改名预览出现"名称未变化 / 新名称重复 / 新名称为空"

这些是 `RenamePlanner` 的冲突标记，冲突项会在执行时被跳过。

建议：
- 检查规则参数是否合理（例如正则替换把所有主体替换成相同结果）
- 如需保留原名避免重复，可使用"顺序编号 + 保留原文件名"

## 3) 复制/下载预览出现"无法创建目标目录"

触发点：`SafExporter.ensureDirectory()` 返回 `null`。

可能原因：
- 目标 Provider 不允许写入/创建目录
- 目标路径某段名称被已有同名文件占用（期望是目录但实际是文件）

建议：
- 更换目标目录
- 确保目标子目录名称不包含特殊字符

## 4) 复制/下载预览出现"目标已存在"

原因：未勾选"覆盖同名"且目标目录已有同名文件。

可选方案：
- 勾选"覆盖同名"（会删除旧文件再写入）
- 调整序号设置，生成不冲突的新文件名
- 使用"避免重复"功能（默认开启），自动跳过已使用的序号

## 5) 执行复制/下载失败数较多

常见原因：
- SAF Provider 对 `renameTo/delete` 支持不一致
- 源/目标目录在执行期间发生变化（文件被外部删除或占用）
- 网络问题（下载时）

建议：
- 先用"复制预览/下载预览"确认无冲突
- 尽量在本地存储或稳定的 Provider 下操作
- 下载时确保网络连接稳定

## 6) 序号没有按预期工作

可能原因：
- 不同子目录的序号是分别维护的
- "避免重复"功能会跳过目标目录已存在的序号
- 手动修改了序号但没有保存

建议：
- 在"设置页"检查当前子目录的序号设置
- 使用"扫描目标目录并跳转到下一个可用序号"功能
- 确认"避免重复"开关的状态
