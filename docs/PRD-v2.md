# 毛毛虫资源管家（maomaochongapp）PRD v2（草案）

> 版本：v2 Draft  
> 日期：2026-03-19  
> 范围：在现有“批量改名 + SAF 导出”的基础上，升级为“面向毛毛虫点读笔磁盘结构的文件管理/复制/下载工具”，并新增“序号（编号）管理”能力。

## 1. 背景与问题

毛毛虫点读笔（非 WiFi 版）常见磁盘目录结构固定，用户的高频动作是：
- 将音频/资源从手机整理后复制到点读笔磁盘的指定目录（如 `MP3/`、`DIYAUDIO/`、`DIYREC/` 等）
- 资源文件需要按“序号”命名，且序号不能重复；需要持续递增并能回溯当前号
- 对已有文件进行查看、筛选、批量改名、批量复制、（可选）批量删除等操作
- 通过链接（URL）下载音频到点读笔磁盘目录，并自动按序号命名

痛点：
- 手机侧整理与 U 盘/点读笔磁盘写入割裂，流程繁琐
- 序号易乱：不知道当前用到多少号，容易重复覆盖或冲突
- 目录固定但 App 目前需要手填导出路径参数，且 UI 逻辑分散

## 2. 产品目标

做一款安卓 App（离线优先）：
1) “设置页”一次性配置**源读取文件夹**与**目标存储文件夹（点读笔磁盘根）**，并持久化
2) App 内即可查看源/目标文件，支持批量选择、批量命名、批量复制导出
3) 提供可靠的“序号管理”：记录当前序号、每次递增、可手动调整、可避免重复
4) 提供两种写入模式：
   - 复制模式：从源选择文件 → 自动按序号改名 → 复制到目标的指定子目录
   - 下载模式：输入/提交 URL → 自动下载到目标指定子目录 → 自动按序号改名

## 3. 目标用户

- 家长：维护点读贴音频、MP3 故事/儿歌资源
- 资源整理者：需要重复导入导出与增量更新

## 4. 点读笔磁盘默认目录（非 WiFi 版）

目标磁盘根目录下通常包含：
- `BOOK/`：书本数据包（`.bnl`）
- `DICT/`：英汉电子词卡文件
- `DIYAUDIO/`：音频贴（自制 DIY 音频）
- `DIYREC/`：录音贴录制音频文件
- `MP3/`：MP3 播放音频
- `DIYREC2/`：系统录制音频文件
- `REC/`：系统录制音频文件

产品要求：
- 目标根目录配置后，子目录下拉默认提供上述列表（并允许自定义/刷新实际存在目录）

## 5. 核心功能需求（MVP v2）

### 5.1 导航与页面结构（Tab）

至少 4 个 Tab：
1) 文件（File Manager）
2) 复制（Copy）
3) 下载（Download）
4) 设置（Settings）

说明：复制与下载必须是单独 Tab；设置必须是单独 Tab。

### 5.2 设置页（Settings）

1) 目录配置
- 配置并持久化：
  - 源读取文件夹（SAF Tree URI）
  - 目标存储文件夹（SAF Tree URI，通常为点读笔磁盘根）
- 可在设置页查看当前已配置的目录名称/URI
- 支持“一键重新选择/清除”

2) 目标子目录配置
- 下拉选择默认子目录（上述 7 个）
- 可手动输入自定义子目录名
- 允许按子目录分别维护序号（见 5.5）

3) 序号配置（编号管理）
- 展示并持久化“当前序号”
- 支持：
  - 手动修改当前序号
  - 每次成功写入（复制/下载）后自动递增
  - 防止序号重复（策略见 5.5）
- 可选增强：
  - 支持“位数（pad）”与“前缀（如 REC）”等命名模板配置（TBD）

### 5.3 文件页（File Manager）

目标：App 内可查看与管理源/目标目录下文件。

功能：
- 展示源目录文件列表（名称、扩展名、大小、修改时间，若可得）
- 展示目标目录（当前子目录）文件列表
- 支持批量选择（多选）
- 支持批量命名（生成预览：旧名 → 新名）
- 支持批量复制（从源到目标子目录）
- 支持对目标目录的基本管理操作（至少：查看；可选：批量删除/重命名，需二次确认）

说明：
- 现有 `RenamePlanner` 可以复用为“批量命名”引擎，但 v2 更强调“序号模式”的稳定性与避免重复。

### 5.4 复制页（Copy）

目标：从源选择一组文件，按序号自动命名并复制到目标子目录。

流程：
1) 选择/确认目标子目录（默认来自设置）
2) 从源文件列表选择若干文件
3) 生成复制预览：
   - 目标路径：`<目标根>/<子目录>/<新文件名>`
   - 冲突提示：目标已存在、命名重复、非法字符等
4) 执行复制
5) 成功后更新：
   - 目标目录文件列表
   - 序号（递增）

可控项：
- 允许在复制页临时调整序号起始值（不会立即覆盖设置，除非用户确认“保存为当前序号”）
- 覆盖策略：覆盖/不覆盖（与现有导出逻辑一致）

### 5.5 序号去重策略（防止重复）

必须实现至少一种防重复方案（建议组合）：
- 方案 A（扫描目标目录）：执行前扫描目标子目录已有文件名，提取已使用序号集合；生成新命名时跳过已存在的序号
- 方案 B（持久化序号）：DataStore 持久化记录“当前序号”；每次写入成功后递增

推荐默认行为：
- 生成预览时：以“当前序号”为起点，遇到已存在的序号则跳过，直到为选中文件分配足够的序号
- 执行完成后：把“最后成功分配的序号 + 1”写回为新的当前序号

说明：
- “如何从文件名提取序号”依赖命名模板（例如 `0001.mp3`、`REC1201.mp3`、`0001_原名.mp3`）；模板需在设计中明确（见设计文档 TBD 项）。

### 5.6 下载页（Download）

目标：根据用户输入的 URL 下载文件到目标子目录，并按序号命名。

需求：
- 输入一个或多个 URL（逐行/粘贴）
- 可选：支持从分享面板接收 URL（后续增强）
- 生成下载预览：
  - URL → 目标文件名 → 目标路径
  - 冲突与覆盖提示
- 执行下载：
  - 支持取消
  - 展示进度与失败原因
- 成功后更新目标列表与序号

约束：
- 需要网络权限；并提供失败重试策略（TBD：重试次数、超时等）
- 文件扩展名：优先从 URL 或 Content-Type 推断；推断失败时使用 `.bin` 或保留空扩展名（TBD）

## 6. 非功能需求

- 离线可用：复制/改名/文件管理在无网情况下可用；下载页仅在有网时可用
- 安全：批量删除/覆盖必须明确提示；默认不覆盖
- 可恢复：序号记录持久化；若 Provider 不支持持久化授权，至少当前会话可用
- 性能：文件列表与预览生成在 IO 线程执行；UI 可取消/禁用按钮防重复触发

## 7. 验收标准（v2 MVP）

- 能在设置页配置并持久化源/目标目录（SAF）
- 能在文件页查看源/目标子目录文件列表
- 复制页：选中文件 → 生成预览 → 复制到目标子目录成功，且序号按规则递增
- 序号不重复：当目标目录已有若干序号文件时，新生成命名会自动跳过冲突序号
- 下载页：输入 URL → 预览 → 下载到目标子目录成功，且序号递增
