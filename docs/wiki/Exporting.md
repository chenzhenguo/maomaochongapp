# 复制导出（SAF Export）详解

实现位置：`app/src/main/java/com/maomaochongapp/export/SafExporter.kt` 与 `MainViewModel.buildCopyPreview/applyCopy`

本项目的复制导出分两步：
1. 生成"复制预览"（只计算，不复制）
2. 执行复制

## 目标路径规则

v2版本的目标相对路径直接使用目标子目录：

`目标子目录`

然后在 UI 中展示为：

`目标目录/<目标子目录>/<新文件名>`

支持的标准目标子目录：
- `BOOK`：书本数据包（`.bnl`）
- `DICT`：英汉电子词卡文件
- `DIYAUDIO`：音频贴（自制 DIY 音频）
- `DIYREC`：录音贴录制音频文件
- `MP3`：MP3 播放音频
- `DIYREC2`：系统录制音频文件
- `REC`：系统录制音频文件

用户也可以输入自定义子目录名。

## 复制预览如何生成

入口：`MainViewModel.buildCopyPreview()`

流程：
1. 获取用户在"文件"页选择的文件列表
2. 根据当前序号设置（起始序号、位数、前缀）和避免重复策略分配序号
3. 计算目标文件名：`prefix + num.padStart(width,'0') + 扩展名`
4. 尝试在目标根目录下创建/定位目标子目录（`SafExporter.ensureDirectory`）
5. 在以下维度标记冲突（优先级从高到低）：
   - 目标目录无法创建：`无法创建目标目录`
   - 新文件名含非法字符 `/` 或 `\\`：`文件名包含非法字符`
   - 未勾选覆盖时，目标目录已存在同名文件：`目标已存在`
   - 序号分配失败（理论上不会发生）

注意：预览阶段会扫描目标子目录现有文件，提取已使用的序号，确保新分配的序号不会重复。

## 执行复制

入口：`MainViewModel.applyCopy()`

执行时会过滤掉 `conflict != null` 的项，只复制可执行的文件：

- 复制模式：`move=false`（v2只有复制，没有移动）
- 覆盖策略：
  - `overwrite=false` 且目标存在同名：跳过
  - `overwrite=true` 且目标存在同名：先删除旧文件再创建新文件

`SafExporter.export()` 的行为：
- 对每个文件执行流式复制（`openInputStream` → `openOutputStream`）
- 结果计数说明：
  - `ok`：复制成功
  - `skipped`：复制被跳过（常见：目标存在且不覆盖）
  - `failed`：源文件找不到 / 复制异常等

## 序号管理

v2版本的核心特性是序号管理：

- **按子目录维护**：不同子目录（MP3、DIYAUDIO、REC等）分别维护序号
- **自动递增**：每次成功复制后，序号自动递增
- **避免重复**：默认开启，会扫描目标目录现有文件，跳过已使用的序号
- **手动调整**：可以在设置页手动修改当前序号
- **自动扫描**：提供"扫描目标目录并跳转到下一个可用序号"功能

## 已知限制（SAF 相关）

- 不同厂商/文件提供者对"持久化授权"支持不一致，可能导致下次进入需要重新授权
- 导出目录创建依赖 SAF Provider 的写入能力；某些外置存储（OTG/U盘）在特定系统上可能不可写
