# 毛毛虫资源管家（maomaochongapp）Wiki

一个离线可用的安卓工具，用于在手机上**批量重命名资源**并按点读笔常见目录结构（如 `BOOK/`、`MP3/`、`DIYAUDIO/`、`REC/`）进行**复制导出**或**下载导入**。

相关文件：
- 产品方案：`docs/PRD-v2.md`（v2 版本）
- 设计文档：`docs/DESIGN.md`
- 代码索引：`project_index.md`

## 这款 App 能做什么（v2 MVP）

- **文件管理**：查看源/目标目录文件，支持批量选择
- **批量改名**：支持序号前缀、正则替换等多种命名模式
- **复制导出**：选中文件按序号重命名后复制到目标子目录
- **下载导入**：输入 URL 列表，自动下载并按序号命名
- **序号管理**：按子目录维护序号，支持自动递增、避免重复

## 使用流程（面向普通用户）

1. **设置页**：选择源文件夹和目标存储文件夹（点读笔磁盘根目录）
2. **文件页**：选择要处理的文件
3. **复制页**或**下载页**：生成预览并执行

### 复制流程
1. 在"文件"页选择要复制的文件
2. 切换到"复制"页，确认目标子目录（如 `MP3`、`DIYAUDIO`、`REC` 等）
3. 点击"生成预览"检查是否有冲突（红色提示）
4. 点击"执行复制"

### 下载流程
1. 在"下载"页输入URL列表（每行一个URL）
2. 确认目标子目录和序号设置
3. 点击"生成预览"检查目标文件名
4. 点击"执行下载"

## 目标目录结构

v2版本直接使用点读笔磁盘的标准目录结构：

`目标目录 / 目标子目录 / <新文件名>`

例如：
- `U盘根目录/MP3/0001.mp3`
- `U盘根目录/DIYAUDIO/REC1201.mp3`
- `U盘根目录/REC/0001.wav`
