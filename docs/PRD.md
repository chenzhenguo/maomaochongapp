# 毛毛虫资源管家（App）产品需求文档（PRD）

更新时间：2026-03-19

## 1. 背景与目标

用户需要把音频/资源文件批量整理到“毛毛虫点读笔（非 WiFi 版）”的磁盘目录结构中，并且在 App 内完成：

- 设置源读取文件夹与目标存储文件夹（通常为毛毛虫磁盘根目录）
- 查看文件、批量选择、批量命名（基于序号）
- 两种写入模式：
  - 复制模式：从“源文件夹”选中若干文件，按序号自动重命名后复制到目标子目录
  - 下载模式：输入 URL 列表，自动下载到目标子目录，并按序号命名
- 序号配置：记录当前序号，每次操作后自动递增；支持手动调整；避免序号重复（与目标目录现有文件冲突）

## 2. 目标用户与使用场景

- 家长/老师：整理 MP3、录音贴音频、音频贴音频、词卡等资源到点读笔
- 高频操作：每天/每周批量导入、连续编号、避免重名覆盖

## 3. 目录约定（目标盘默认目录）

非 WiFi 版点读笔常见目录（目标根目录下）：

- `BOOK`：书本数据包（官网提供 bnl 格式）
- `DICT`：英汉电子词卡文件
- `DIYAUDIO`：音频贴自制 DIY 文件
- `DIYREC`：录音贴录制的音频文件
- `MP3`：MP3 播放音频文件
- `DIYREC2`：系统录制的音频文件
- `REC`：系统录制的音频文件

App 在“目标子目录”选择器中默认提供以上选项，同时允许自定义输入（兼容未来目录变化）。

## 4. 功能需求

### 4.1 页面结构（Tab）

App 顶部/底部使用 Tab 切换：

1) **设置**
2) **文件**
3) **复制**
4) **下载**

### 4.2 设置页

必须支持：

- 选择源读取文件夹（SAF：OpenDocumentTree）
- 选择目标存储文件夹（SAF：OpenDocumentTree；通常为毛毛虫磁盘根目录）
- 目标子目录选择（默认目录 + 自定义）
- 序号配置
  - 当前序号（Next Index）
  - 位数（Width，默认 4，例如 `0001`）
  - “避免重复”开关（默认开启）
  - 可选：一键“扫描目标目录，跳到下一个可用序号”
- 覆盖同名开关（默认关闭）

序号规则（基础版）：

- 文件名 = `序号(零填充到位数)` + `原扩展名`
  - 示例：`0001.mp3`、`0123.wav`

### 4.3 文件页（文件管理）

必须支持：

- 在 App 内查看文件列表
  - 源文件夹文件列表
  - 目标子目录文件列表（目标根目录 + 目标子目录）
- 源文件夹文件支持多选
  - 全选 / 全不选
  - 显示当前选择数量
- 对选中文件进行批量命名（在“源文件夹内改名”）
  - 生成改名预览
  - 执行改名
- 文件查看（至少支持“打开”）
  - 通过系统 Intent 打开选中文件（音频/文本/其他由系统处理）

### 4.4 复制页（复制模式）

必须支持：

- 使用“文件页”选中的源文件作为输入
- 允许设置/覆盖本次操作起始序号（可选）
- 生成复制预览（oldName → newName，展示目标路径与冲突）
- 执行复制到目标子目录
- 操作结束后：
  - 自动更新“当前序号”（递增到本次分配的最后一个序号之后）
  - 给出成功/跳过/失败统计

冲突处理：

- 避免重复开启时：优先跳过目标目录已存在的序号，分配下一个可用序号
- 若仍出现冲突（例如覆盖同名关闭且目标已存在）：该条目标记冲突并不执行

### 4.5 下载页（下载模式）

必须支持：

- 输入 URL 列表（每行一个）
- 生成下载预览（URL → 目标文件名/路径/冲突）
- 执行下载到目标子目录（需要 `INTERNET` 权限）
- 操作结束后自动更新“当前序号”

文件扩展名策略（基础版）：

- 优先使用 URL 路径中的扩展名（如 `.mp3`、`.wav`）
- 如果 URL 无扩展名：默认使用 `.bin`（或后续优化：根据 `Content-Type` 推断）

## 5. 非功能需求

- 安全：使用 SAF（Storage Access Framework）访问目录；只在用户授权范围内读写
- 可恢复：保存上次选择的目录 URI 与序号配置（在权限仍有效时自动恢复）
- 性能：目录文件数较多时避免卡顿（IO 在后台线程）
- 可用性：所有写入操作都先有预览；UI 显示冲突原因

## 6. 里程碑（建议）

1) 完成 Tab 架构与设置页迁移
2) 文件页：源/目标浏览 + 多选 + 批量改名（源内）
3) 复制页：序号分配 + 预览 + 复制写入 + 序号递增
4) 下载页：URL 列表下载 + 预览 + 序号递增
