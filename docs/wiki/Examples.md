# 示例（从需求到操作）

以下示例用来快速对齐"该选哪种规则、参数怎么填、最终文件会变成什么样"。

## 示例 1：点读贴（REC1201…）

目标：把一批音频变成 `REC1201.mp3`、`REC1202.mp3` …，导出到 `DIYAUDIO/`。

操作建议：
1. **设置页**：选择源文件夹和目标目录（点读笔磁盘根目录）
2. **设置页**：选择目标子目录为 `DIYAUDIO`
3. **文件页**：选择要处理的音频文件
4. **复制页**：确认序号前缀为 `REC`，起始序号为 `1201`
5. 点击"生成预览"检查是否有冲突
6. 点击"执行复制"

结果结构：
`目标目录/DIYAUDIO/REC1201.mp3` …

## 示例 2：故事机/播放列表（0001.mp3…）

目标：按文件名排序生成 `0001.mp3`、`0002.mp3`…，导出到 `MP3/`。

操作建议：
1. **设置页**：选择源文件夹和目标目录
2. **设置页**：选择目标子目录为 `MP3`
3. **文件页**：选择要处理的音频文件
4. **复制页**：确认序号前缀为空，起始序号为 `1`，位数为 `4`
5. 点击"生成预览"检查是否有冲突
6. 点击"执行复制"

如果你希望导出后还能看出原名：
- 在"复制页"临时调整命名规则（但v2主要使用序号模式）

## 示例 3：下载音频资源

目标：从网络下载音频并自动按序号命名。

操作建议：
1. **设置页**：选择目标目录（点读笔磁盘根目录）
2. **设置页**：选择目标子目录（如 `MP3`）
3. **下载页**：输入URL列表（每行一个）
   ```
   https://example.com/song1.mp3
   https://example.com/song2.mp3
   ```
4. 确认序号设置（起始序号、位数、前缀）
5. 点击"生成预览"检查目标文件名
6. 点击"执行下载"

结果：
- 自动下载文件到目标子目录
- 按序号自动命名：`0001.mp3`、`0002.mp3`…

## 示例 4：REC目录特殊处理

目标：为REC目录使用REC前缀命名。

操作建议：
1. **设置页**：选择目标子目录为 `REC`
2. 系统会自动将序号前缀设置为 `REC`
3. 起始序号会自动从目标目录现有文件中扫描确定
4. 在"复制页"或"下载页"执行操作

结果：
`目标目录/REC/REC0001.wav`、`REC0002.wav`…
